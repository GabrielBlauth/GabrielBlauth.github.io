DublinBikes API

A real-time .NET 8 Web API tracking Dublin bike-station availability on Azure Cosmos DB.

Overview

A .NET 8 Web API that tracks real-time station availability across Dublin's bike-share network, backed by Azure Cosmos DB. Built to go beyond a simple CRUD app — with a background service simulating live data, full test coverage, and an automated CI/CD pipeline.

Real-Time Data, Verified

A background service (IHostedService) updates every station's availability automatically every 15 seconds, simulating real-time bike movement instead of static data.

Rather than just trusting the code, I verified this end-to-end: pulling the same station's document from Cosmos DB twice, 20 seconds apart, and confirming the numbers changed on their own — the difference between "should work" and "does work."

Filtering, Sorting & Pagination

The API supports filtering by status and minimum bikes available, sorting by any field, and full pagination — all combinable in a single request.

Full CRUD operations are backed by input validation and correct HTTP status codes (200, 201, 400, 404, 409), documented end-to-end via Swagger/OpenAPI.

Live on Azure Cosmos DB

Station data is persisted in Azure Cosmos DB rather than a static file — meaning the API reflects a real, changing dataset, not a fixture.

Tech Stack

C# · .NET 8 · Azure Cosmos DB · Swagger/OpenAPI · xUnit · GitHub Actions
